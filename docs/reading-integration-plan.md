# 사주·별자리 통합 풀이 구성 (2026-11-09)

이번 생활 장면 편집의 기준 커밋: f393b6b6264238aaef7eb856f722e18ec9f8ba6e. 현재 규칙은 `western-astrology.md`의 2026-11-09 본문 편집 절과 함께 읽는다.

## 원칙

- 한 분야는 제목 하나, 생활 장면, 판정 하나, 부담 항목 하나로 읽는다. 기존 문장과 통합 문장을 모두 보존한다는 이유로 제목·판정·요약을 추가하지 않는다.
- 사주와 별자리 계산 근거를 유지한다. `life-reading.js`는 나이에 맞는 장면과 조건을 고르며 동일 원인의 반복은 행동·책임·비용으로 이어 쓴다. `reading-pool.js`는 후보 전체를 붙이지 않고 최종 생활 흐름에 필요한 후속 장면을 선택한다.
- 집안에서 받은 배움·생활 지원과 주거·진로 지원의 차이는 관련 가족 문단에서 설명한다.
- 이동 비용은 실제 지출 본문과 비용 항목에 둔다. 두 번째 ‘당신은’ 판정으로 붙이지 않는다.
- 도입부의 추가 근거는 마지막 판정 전에 놓는다. ClosingReading의 전체풀이에는 이미 선택한 분야들을 잇는 생활 흐름이 있으므로 별도 분야 판정이나 범용 연결문을 다시 끼워 넣지 않는다.

## 시기별 흐름

- 도입부 뒤에 과거 한 개를 읽는다. 끝부분에는 올해·내년·현재 10년만 기본 표시하고 월운·이후 10년·나머지 과거·그래프는 접는다. 실제 행성 접촉과 기존 절기 경계는 그대로 계산한다.
- 기본 풀이와 별자리 흐름을 보통 문단으로 이어 쓴다. 별도 테두리 안에서 같은 설명을 다시 시작하지 않는다.
- 동일한 해석의 여러 접촉은 합쳐 설명하고 정확한 모든 접촉 기간과 근거는 보관한다. 본문에는 새로운 주제 한 개만 잇고 모든 재접촉 시점과 긴 설명은 날짜 상세에 남긴다.
- 상세 접촉 날짜는 각 시기의 ‘시기 자세히 보기’에서 펼친다. 긴 기간 안에서 몇 차례 발생하는 흐름을 10년 내내 계속된다고 말하지 않는다.
- 앞 단계에서 중복을 제거한 다음 대운의 본문을 원본으로 다시 덮어쓰지 않는다. 충돌 조정도 실제 표시할 본문에 적용한다.
- 출생시간 미상은 하루 전체에 성립하는 조건만 사용하고 달·상승궁·하우스 정밀 판정은 제외한다.
- 같은 주제·대상·적용 범위의 충돌만 실제 근거가 있는 불리한 해석으로 조정한다. 좋은 접촉만 있을 때 흉운을 만들지 않는다.

## 검증 기준

- 다양한 입력에서 제목·판정·항목을 하나씩 표시하고 선택 근거를 유지한다. 청소년·청년·중장년·고령, 남녀, 생시 유무를 비교한다. 자녀 조건이 최종 결론에서 사라지지 않아야 한다.
- 이동 비용, 집안 지원, 관계 비용, 정신적 긴장과 신체 회복의 연결은 해당 조건이 있을 때만 사용한다.
- 기간 경계, 출생시간 미상, 역행 재접촉, 지지/마찰 충돌, 중복 본문 재등장 방지를 검사한다.
- 렌더러는 판정 뒤에 풀이를 다시 붙이지 않으며 시기 문단과 펼칠 수 있는 날짜를 한 번씩 표시한다.
- Worker 계산 후 PC 및 390px 폭의 실제 결과 화면에서 분야별 구성과 날짜 펼치기를 확인한다.
