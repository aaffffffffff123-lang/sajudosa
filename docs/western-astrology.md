# 서양 출생차트와 사주 풀이

`western.js`는 행성 계산, 출생차트 표시, 사주 본문에 연결할 고정 원고를 담당한다. 기존 `index.html`의 사주 판정과 돈·일·관계 분기를 유지한다. 전투와 순응 장면은 변경하지 않는다.

## 계산 기준

- Astronomy Engine의 `GeoVector(body, utc, true)` → `Ecliptic(vector)`: 지구 중심, 관측 시점의 열대황도, 광행차·광행시간 보정.
- 출생지의 당시 표준시와 서머타임은 기존 `wallToUtc`를 사용한다. 사주 계산의 진태양시 보정을 서양 차트에 다시 적용하지 않는다.
- 상승궁은 황도와 동쪽 지평선의 교점. 하우스는 상승궁의 별자리 전체를 1하우스로 삼는 홀사인 방식이다.
- 합·사각·삼각·대립은 6도, 육각은 4도의 허용 범위를 쓴다. 각도 자체와 오차도 상세 표시에 남긴다.
- 생시 미상은 현지 날짜의 첫 유효 시각부터 마지막 유효 시각까지 검사한다. 하루가 23시간 또는 25시간이어도 이 범위를 그대로 쓴다. 상승궁·하우스·행성 간 각도·정확한 도수를 내지 않는다.
- 생시 미상의 별자리는 30분 간격과 양 끝 시각을 확인하고 경계 부근은 보수적으로 후보를 넓힌다. 하루 도중 바뀔 수 있는 태양·달 등을 정오의 별자리 하나로 확정하지 않는다.
- 출생지는 기존 도시 목록의 중심 좌표를 쓴다. 좌표가 없으면 상승궁과 하우스를 생략한다. 현재 목록 밖의 극지 출생지는 별도 지원이 필요하다.

## 원고 유지

사용자가 확정한 원고는 `COPY`에 그대로 보관한다. 위로·희망·훈계하는 마무리를 덧붙이거나 호출마다 바꿔 쓰지 않는다. 기존 `comfort` 재물운에 긴 원고를 연결하고 다른 재물운 유형은 원래 분기를 지킨다.

정인의 노출 횟수는 실제 사주에서 센다. 달·토성의 2하우스 합, 목성의 8하우스, 태양·화성의 사각 등은 실제 서양 차트에서 해당할 때만 말한다. 합의한 개인 예시의 배치를 모든 사람에게 적용하지 않는다. 삼각·육각이나 목성의 재물 배치를 흉한 배치로 바꾸지 않는다. 빈 하우스를 그 영역의 부재로 해석하지 않는다.

`v5Reading`이 화면용 문구를 완성하고 `renderResult`는 그 순서를 그대로 렌더한다. 긴 재물운의 마지막은 `COPY.ending`으로 끝내며 그 뒤에 다른 이치 문장을 붙이지 않는다.

## 의존성과 검사

공식 원본: https://github.com/cosinekitty/astronomy/blob/master/source/js/astronomy.browser.min.js

고정 원본 blob: `fc5ab5c406c6fd64bdd537772e4cc7c8d438275b`. MIT 고지와 `assets/astronomy-LICENSE.txt`를 함께 보존한다. 계산은 브라우저 안에서 이뤄지며 출생정보를 외부로 보내지 않는다.

```sh
node --test tests/reading-copy.test.cjs tests/reading-evidence.test.cjs tests/reading-flow.test.cjs tests/western.test.cjs
```

검사는 좌표 변환, 동쪽 지평선과 실제 상승 방향, 날짜 경계, 음양력 일치, 한국·해외 서머타임, 같은 입력의 문구 일치, 합의 원고의 순서와 최종 문장, 라이브러리 실패 시 기존 사주 유지까지 포함한다. DOM 대역을 통한 렌더 검사는 실제 모바일 브라우저의 시각 검사를 대신하지 않는다.
