# 서양 출생차트와 사주 풀이

`western.js`는 행성 계산과 맨 위 별자리 카드·접힌 출생차트만 그린다. 본문 문단은 `reading-pool.js`가 고르고, 별자리는 문단을 고르는 조건으로 쓰고 그 결과를 전체 총평에도 반영한다(2026-11-07). 기존 `index.html`의 사주 판정과 돈·일·관계 분기를 유지한다. 전투와 순응 장면은 변경하지 않는다.

## 계산 기준

- Astronomy Engine의 `GeoVector(body, utc, true)` → `Ecliptic(vector)`: 지구 중심, 관측 시점의 열대황도, 광행차·광행시간 보정.
- 출생지의 당시 표준시와 서머타임은 기존 `wallToUtc`를 사용한다. 사주 계산의 진태양시 보정을 서양 차트에 다시 적용하지 않는다.
- 상승궁은 황도와 동쪽 지평선의 교점. 하우스는 상승궁의 별자리 전체를 1하우스로 삼는 홀사인 방식이다.
- 합·사각·삼각·대립은 6도, 육각은 4도의 허용 범위를 쓴다. 각도 자체와 오차도 상세 표시에 남긴다.
- 생시 미상은 현지 날짜의 첫 유효 시각부터 마지막 유효 시각까지 검사한다. 하루가 23시간 또는 25시간이어도 이 범위를 그대로 쓴다. 상승궁·하우스·행성 간 각도·정확한 도수를 내지 않는다.
- 생시 미상의 별자리는 30분 간격과 양 끝 시각을 확인하고 경계 부근은 보수적으로 후보를 넓힌다. 하루 도중 바뀔 수 있는 태양·달 등을 정오의 별자리 하나로 확정하지 않는다.
- 출생지는 기존 도시 목록의 중심 좌표를 쓴다. 좌표가 없으면 상승궁과 하우스를 생략한다. 현재 목록 밖의 극지 출생지는 별도 지원이 필요하다.

## 화면

결과 화면은 사주풀이 틀(원국 → 상징 → 오행 → 성격 → 분야별 운 → 세운·월운·대운 → 총평) 대신 읽는 길을 따른다(2026-11-07 결정): 믿음 → 판정 → 무게 → 출구 닫기.

1. 「당신이 태어난 때」: 사주 네 기둥, 다섯 기운 비율 막대(오행 별 문양), 접힌 원국 표, 별자리 세 장과 접힌 출생차트.
2. 「당신을 보니」 책자: 첫머리에 나를 나타내는 상징 한 줄, 이어서 생활 장면 세 문단.
3. 「타고난 운명」 카드: 집안 판정 → 당신을 부리는 기운 → 타고난 성향. 마지막 「전체 풀이」와 같은 카드 모양이다.
4. 일곱 칸(일 → 돈 → 몸 → 짝과 관계 → 가족과 부양 → 귀인 → 권한과 책임). 칸마다 첫머리 그림이 있고 팔자 줄 끝에 「사주도사」 도장이 찍힌다. 칸 사이 점선은 없다.
5. 「지나온 해와 앞날」 연표: 지나온 해 → 올해·이번 달 → 내년 → 10년 그래프와 10년 줄 → 해의 이치 → 「그만큼 더 감당할 것」. 모두 같은 줄 모양이고 적용 기간·전환 시각 같은 계산 안내는 작은 글씨 한 줄이다.
6. 「전체 풀이」 → 마지막 줄 → 족치기 장면.

- 상단 막대: 스크롤하면 「사주도사」 글자가 작아지고 지금 읽는 칸(그림·이름표 표시·이름)이 뜬다. 막대 아래 붉은 선은 읽은 만큼 늘어난다. PC에서는 칸 이름을 본문 왼쪽 끝에 맞춘다.
- 흑막이 드러나는 연출(움직이는 부분은 스크립트의 `DOOM`): 배경과 색이 점점 탁해지고, 왼쪽 위 도사 얼굴이 파충류로 바뀌고, 이름표 표시가 일까지 네모 → 돈부터 세모 → 「지나온 해와 앞날」부터 눈 달린 세모로 바뀐다. 상단 머릿말도 같은 표시를 쓴다. 칸 그림에도 세모가 숨어 있다(돈 지폐의 피라미드, 아이 신발 상표, 귀인 구름 속 눈, 관운 도장 자국). 오행 별 문양은 다섯 기운 막대 옆, 뱀 문양은 연표 이름표 옆, 마지막 문장 뒤에는 세모 눈이 떠오른다.
- 맨 위 「당신이 태어난 때」에 사주 네 기둥과 같은 카드로 태양·달·상승궁을 그린다. 12궁 그림은 십이지 그림과 같은 결로 `index.html`의 `w-aries`…`w-pisces` 심볼에 있다.
- 카드 아래에는 확정된 태양·달만 한 줄씩 푼다(`SUN`·`MOON`의 첫 문장). 후보가 둘인 별은 풀지 않는다.
- 「사주 원국 자세히 보기」(만세력 한자·지장간·12운성·다섯 기운 글자 수와 풀이·대운·신살·합충형파해·칸별 근거)와 「내 출생차트 자세히 보기」(차트 휠·행성 표·각도)를 접어 둔다. 본문에서 뺀 근거와 배치 설명은 여기에만 있다.
- 별자리 부분도 사주와 같은 색을 쓴다. 남색 강조를 쓰지 않는다.

## 본문 문단(`reading-pool.js`)

- 칸마다 후벼파는 문단을 여러 개 써 두고 문단마다 사주·별자리 조건을 붙인다. 조건이 맞는 문단은 모두 붙이고 한 사람이 받는 문단 수에 상한을 두지 않는다.
- 칸 순서: 제목 → 장면 → 한 방 → 조건이 맞는 문단 → 팔자 줄. 한 방은 원래 이치를 끝에 글자 그대로 품는다(이름표 없음).
  - 돈: 유형별 장면 → 유형별 한 방(`LEAD`) → 문단 → 격차 문단 → 팔자 줄 → 돈이 새는 곳.
  - 일·몸·짝과 관계·가족과 부양·귀인·관운: 원인별 장면 → 원인별 한 방(`OPENING`) → 문단 → 팔자 줄. 몸의 한 방은 이치 갈래(strong·weak·self·checking·night), 짝의 한 방은 house·money·silence·base 갈래로 고른다.
  - 한 방의 첫 문장은 칸마다 다르게 꺼낸다: 일은 맡기는 쪽의 셈, 몸은 괜찮아 보이는 이유, 짝은 흔히 하는 말, 가족은 자기 다짐, 귀인은 남에게 듣는 조언, 관운은 품기 쉬운 기대.
  - 「틀린 곳을 짚는」 일 갈래(hurt_officer)는 성향 카드·관운과 늘 함께 나와서 일 칸은 「더 나은 방법도 시키지 않은 방법이면 다시 합니다」 얘기로 돌렸다(머리줄·이치·팔자 줄 교체).
- 본문에는 별자리 이름·하우스·행성·십성 같은 용어를 쓰지 않는다. 같은 문장을 두 번 쓰지 않는다.
- 칸마다 짓밟는 방식이 다르고 부조리 주제 하나는 한 칸에만 둔다. 그 칸 첫머리와 같은 얘기를 하는 문단은 `not`·`workNot`·`coreNot`·`skip`으로 뺀다.
- 사용자가 확정한 재물 원고는 `COPY`에 그대로 보관한다. 글자를 바꾸지 않고 붙는 조건만 넓혔다.
- 귀인 글자가 있는 사람과 없는 사람의 문단은 섞지 않는다.

## 기간 문장

「지나온 해와 앞날」 연표 한 곳에서 지나온 해 → 올해·이번 달 → 내년 → 10년 흐름 순서로 읽는다. 앞에서 나온 문장은 뒤에서 다시 쓰지 않는다. 올해 풀이가 지나온 해와 같으면 「○○년과 같은 일이 다시 옵니다.」로 줄인다. 기간마다 덧붙이던 풀이는 뺐다.

## 첫 화면과 전체 총평 (2026-11-07)

- 첫 화면은 로고, 정상 갓의 도사, 해·달 장식, 옅은 별자리 원판, 「사주와 별자리에 담긴 내 운명」만 남긴다. 「사주 · 서양 점성술」과 항목 나열은 뺐다. 금색 궤도·행성·반짝임은 첫 화면에서 빼고 수정구슬은 로딩 장면에만 둔다.
- 전체를 묶는 제목·총평·각주는 「운명」으로 쓴다. 도사의 각 칸 마무리와 인물 대사의 「팔자」, 실제 사주를 가리키는 원국·오행·대운 명칭은 유지한다.
- 총평은 집안·일의 판정을 유지하면서 별자리 때문에 실제로 추가된 본문 문단 하나를 함께 요약한다. 같은 사주에서 별자리를 뺀 조건과 비교해 `westernAddedIds`를 남기고, 제외 조건까지 통과한 문단만 사용한다. 관계 칸을 먼저 살피고 해당 내용이 없으면 일·돈·몸·권한·가족·귀인 순서로 살핀다. 근거는 `verdictEvidence`에 남긴다.
- 총평에 새 사건이나 전문 용어를 붙이지 않는다. 별자리로 추가된 내용이 없으면 사주 기반 총평을 유지한다. 계산 실패·생시 미상에서는 실제로 확보한 조건만 쓴다. 손에 들고 있는 종이에도 화면과 같은 총평을 넘긴다.
