# 서양 출생차트와 사주 풀이

`western.js`는 행성 계산과 맨 위 별자리 카드·접힌 출생차트만 그린다. 본문 문단은 `reading-pool.js`가 고르고, 별자리는 그 문단을 고르는 조건으로만 쓴다(2026-11-07 결정). 기존 `index.html`의 사주 판정과 돈·일·관계 분기를 유지한다. 전투와 순응 장면은 변경하지 않는다.

## 계산 기준

- Astronomy Engine의 `GeoVector(body, utc, true)` → `Ecliptic(vector)`: 지구 중심, 관측 시점의 열대황도, 광행차·광행시간 보정.
- 출생지의 당시 표준시와 서머타임은 기존 `wallToUtc`를 사용한다. 사주 계산의 진태양시 보정을 서양 차트에 다시 적용하지 않는다.
- 상승궁은 황도와 동쪽 지평선의 교점. 하우스는 상승궁의 별자리 전체를 1하우스로 삼는 홀사인 방식이다.
- 합·사각·삼각·대립은 6도, 육각은 4도의 허용 범위를 쓴다. 각도 자체와 오차도 상세 표시에 남긴다.
- 생시 미상은 현지 날짜의 첫 유효 시각부터 마지막 유효 시각까지 검사한다. 하루가 23시간 또는 25시간이어도 이 범위를 그대로 쓴다. 상승궁·하우스·행성 간 각도·정확한 도수를 내지 않는다.
- 생시 미상의 별자리는 30분 간격과 양 끝 시각을 확인하고 경계 부근은 보수적으로 후보를 넓힌다. 하루 도중 바뀔 수 있는 태양·달 등을 정오의 별자리 하나로 확정하지 않는다.
- 출생지는 기존 도시 목록의 중심 좌표를 쓴다. 좌표가 없으면 상승궁과 하우스를 생략한다. 현재 목록 밖의 극지 출생지는 별도 지원이 필요하다.

## 화면

- 맨 위 「당신이 태어난 때」에 사주 네 기둥과 같은 카드로 태양·달·상승궁을 그린다. 12궁 그림은 십이지 그림과 같은 결로 `index.html`의 `w-aries`…`w-pisces` 심볼에 있다.
- 카드 아래에는 확정된 태양·달만 한 줄씩 푼다(`SUN`·`MOON`의 첫 문장). 후보가 둘인 별은 풀지 않는다.
- 「사주 원국 자세히 보기」(만세력 한자·지장간·12운성·대운·신살·합충형파해·칸별 근거)와 「내 출생차트 자세히 보기」(차트 휠·행성 표·각도)를 접어 둔다. 본문에서 뺀 근거와 배치 설명은 여기에만 있다.
- 별자리 부분도 사주와 같은 색을 쓴다. 남색 강조를 쓰지 않는다.

## 본문 문단(`reading-pool.js`)

- 칸마다 후벼파는 문단을 여러 개 써 두고 문단마다 사주·별자리 조건을 붙인다. 조건이 맞는 문단은 모두 붙이고 한 사람이 받는 문단 수에 상한을 두지 않는다.
- 칸 순서: 제목 → 장면 → 이치(이름표 없이 문단으로) → 조건이 맞는 문단 → 팔자 줄. 돈 칸은 유형별 장면 → 유형별 한 방(원래 이치를 품음) → 문단 → 격차 문단 → 팔자 줄 → 돈이 새는 곳.
- 본문에는 별자리 이름·하우스·행성·십성 같은 용어를 쓰지 않는다. 같은 문장을 두 번 쓰지 않는다.
- 칸마다 짓밟는 방식이 다르고 부조리 주제 하나는 한 칸에만 둔다. 그 칸 첫머리와 같은 얘기를 하는 문단은 `not`·`workNot`·`coreNot`·`skip`으로 뺀다.
- 사용자가 확정한 재물 원고는 `COPY`에 그대로 보관한다. 글자를 바꾸지 않고 붙는 조건만 넓혔다.
- 귀인 글자가 있는 사람과 없는 사람의 문단은 섞지 않는다.

## 기간 문장

지나온 해 → 올해·내년 → 현재 월운 → 10년 흐름 순서로 읽는다. 앞에서 나온 문장은 뒤에서 다시 쓰지 않는다. 올해 풀이가 지나온 해와 같으면 「○○년과 같은 일이 다시 옵니다.」로 줄인다. 기간마다 덧붙이던 풀이는 뺐다.
